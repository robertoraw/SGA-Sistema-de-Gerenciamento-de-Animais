# QUAL O PROJETO RESOLVE?

    Dentro de propriedades de pequenos produtores há um problema que prevalece durante anos: a falta de controle preciso sobre cada animal. Isso é um grande gargalo para produtores agropecuarios, esse problema gera outro chamado Custos Invisiveis, que é quando um produtor não tem dados suficientes para tomar uma decisão rápida.

## A QUEM SE DESTINA O SISTEMA?

    O sistema se destina a pequenos produtores agropecuarios que precisam gerir suas propriedades com precisão e eficiência. Dentro do sistema existem camadas de acessos, desde o proprietário, funcionários e até terceiros que precisam ter acesso a informações.

## Informações detalhadas do projeto:

    O projeto tem por objetivo ser atualizado ao decorrer do tempo com novas funcionalidades, sendo mantido constantemente atualizado.

    Funções do Sistema de Gerenciamento de Animais (SGA):
    Cadastrar animais;
    Pesquisar por animais;
    Incluir rebanhos;
    Pesquisar por rebanhos;
    Realizar compra por CPF ou CNPJ;
    Realizar venda por CPF ou CNPj;
    Agendar vacinas;
    Acompanhar animais de maneira individual;
    Cadastrar funcionários;
    Verificar quem é responsável por cada animal ou rebanho;
    Cadastrar pastos;
    Verificar situação de cada pasto;
    Solicitar ajuda veterinária;


## POR TRÁS DOS BASTIDORES

    O front-end será desenvolvido em Java.

    O back-end será desenvolvido em python, sendo ele responsável pelo sistema do SGA, onde será usado como banco de dados o sistema
    MySQL e terá uma API responsável por conectar todo o Back-End com o Front-End.
